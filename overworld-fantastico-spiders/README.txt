OVERWORLD FANTÁSTICO — PATCH DE ARANHAS (JAVA 26.2)

Este patch aumenta moderadamente o peso de spawn natural das aranhas:
- Jungle: 100 -> 140
- Sparse Jungle: 100 -> 140

Todos os demais spawners, recursos, estruturas e características desses biomas
permanecem iguais aos dados vanilla do Java 26.2.

INSTALAÇÃO
1. Coloque este ZIP na pasta <mundo>/datapacks junto do Overworld Fantástico.
2. Dê prioridade maior a este patch.
3. Execute /reload ou reabra o mundo.
4. Confira com /datapack list enabled.

O efeito vale em chunks já existentes, pois altera a seleção de spawn natural.
Não aumenta o limite global de monstros nem o tamanho dos grupos de aranhas.
